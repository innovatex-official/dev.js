# Governance

dev.js is maintained by InnovateX as a CS lab community project.

## Maintainers

Maintainers are responsible for keeping the project simple, runnable, documented, and useful for learning. Large rewrites should be avoided unless they make the system easier to understand.

## Contributions

Contributions should be small and easy to review. Prefer improvements that make the framework slice clearer: tests, docs, examples, diagnostics, route behavior, and CLI usability.

## Decisions

This repository is pre-`1.0.0`, experimental, and not API-stable. Breaking changes are acceptable when they simplify the codebase or improve the learning value.

## Local Validation

Contributors should run local validation before sharing changes.
